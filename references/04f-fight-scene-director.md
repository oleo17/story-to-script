# 04F：漫剧打戏导演增强层

> 本文件用于把 `story-to-script` 的 04 分镜升级为可执行的漫剧打戏导演流程。它吸收专业打斗 Skill 的“战术、空间、动作因果、轨迹图、镜头职责”方法，但仍服从本项目的 05 资产库、04 分镜格式和 06 多模型提示词适配。

---

## 0. 触发条件

只有命中以下情况时读取本文件：

1. 剧本或用户明确出现打斗、战斗、交锋、武打、追击对抗、兵器战、异能战、群战、Boss 战。
2. 用户要求“动作戏更专业 / 打戏更强 / 先设计攻防 / 保持人物场景一致 / 生成轨迹图 / 生成站位图”。
3. 04b 速查库不足以支撑动作因果、空间路线或多人攻防。
4. 06 输出目标是 Seedance 2.5 或 MiniMax H3，且本段含有强动作、复杂运镜、首尾帧、多人调度或多模态参考。

普通文戏、简单走位、无对抗追逐、情绪运镜，不读取本文件。

---

## 1. 总原则

1. **资产优先**：不得更改 05 已锁定的 `CH/SC/PR/CO/ST/CL/NP/SCV/MAP/SB/FF/CR`。所有打戏设计必须使用既有角色、场景、服装、武器、道具和段末状态。
2. **剧情优先**：打戏只服务本集剧情任务，不为了炫技新增胜负、能力、武器或无关招式。
3. **动作可读**：每个打斗镜头必须写清谁先动、动作目标、接触或近失、对手反应、受力结果、空间变化和下一拍条件。
4. **空间连续**：锁定角色左右方位、摄影机安全侧、前中远景、障碍物、移动路线、武器位置和场景破坏账本。
5. **一镜一责**：每个镜头只承担一个主要信息：建立空间、起手、接触、反应、结果、反转或段末钩子。
6. **非现实教学**：只设计虚构、影视化、漫剧化的表演动作，不输出现实伤人教学、致残技巧或规避执法指导。
7. **不替代 04/06**：本文件先产出打戏 Clip 合同，再回填 04 的 11 字段，最后交给 06 多模型适配。

---

## 2. 打戏 Clip 合同

进入正式分镜前，先建立下列合同。若用户只要最终分镜，可以内部建立，不必完整展示；但输出结果必须体现这些信息。

```text

替换对象：第X集 / Clip X / 原分镜标题
输出模型：Seedance 2.0 / Seedance 2.5 / MiniMax H3（三模型并行，除非用户指定单模型）
建议时长：____ 秒
画幅：9:16 / 16:9 / 其他

资产绑定：
CH001：
CH002：
SC001：
PR001：
CO：
ST：
CL：
MAP/SB：
FF：
参考图预算：

战斗目的：
双方战术差异：
空间轴线：
初始站位：
动作链：
镜头职责：
接触点与受力结果：
武器/道具/能力连续性：
场景破坏账本：
声音与同步音效：
段末状态：
禁止项：
```

### 合同硬规则

- `战斗目的` 不能写“打一架”，必须写清叙事功能，例如试探、压制、逃脱、救人、拖延、破防、反杀、暴露弱点、逼出能力。
- `双方战术差异` 至少在距离、移动、攻击方式、防守方式或力量速度上有 2 项不同。
- `空间轴线` 必须写成画面语言：谁在画面左侧、谁在右侧，摄影机保持哪一侧，移动沿哪个方向。
- `动作链` 必须用“起手 -> 接触/近失 -> 对手回应 -> 受力/位移 -> 结果 -> 下一拍条件”写。
- `段末状态` 必须可交给下一段继承：角色姿态、左右位置、距离、武器/道具位置、伤势/疲劳、光影、镜头方向。

## 3. 战斗档案

每名参战者建立 8 项战斗档案：

```text
角色：
优势距离：
起手姿态：
移动方式：
主攻方式：
防守与反制：
武器/道具/能力资源：
力量节奏：
受击反应：
```

规则：

1. 不同角色的战斗档案不能雷同。
2. 远程角色必须管理视线、弹道、冷却或消耗；近战角色必须说明如何接近、如何被阻止。
3. 体型差、年龄差、伤势差、武器差要体现在受力反馈和动作频率中。
4. 如果角色上游设定不擅长战斗，不要突然变成高手；可以设计误打误撞、借环境、被动闪避、短暂爆发或逃脱。

## 4. 空间与轨迹设计

打戏必须先做最小空间图，而不是直接写镜头。

```text
空间锚点：门 / 窗 / 桌 / 柱 / 台阶 / 墙 / 车辆 / 人群 / 水面 / 屏风等
起点：A 在画面____，B 在画面____，距离____
移动路线：A 从____到____，B 从____到____
摄影机安全侧：摄影机保持在____侧，不切到____反方向
前中远景层次：
障碍物与可交互物：
场景破坏账本：
```

需要生图辅助时，05 可以补出：

- `MAP`：站位、移动路线、摄影机安全区、轴线。
- `FF`：第 0 秒首帧，锁构图、人物初始位置、道具、光影。
- `SCV`：空间多角度空场图，只参考透视和固定物。
- `SB`：窗内外、柜台内外、车内外、门内外等空间侧别。

如果 MAP/FF/SCV/SB 与现有分镜冲突，先修资产或首帧，不进入 06。

## 5. 动作链编排

每一拍必须包含：

```text
发起者：
战术目的：
起手/蓄力：
动作路径：
接触点或近失关系：
对手回应：
受力方向：
位移/环境反馈：
下一拍条件：
```

### 动作密度

- 4-6 秒：1 个核心动作闭环，最多 2-3 个微交锋。
- 7-9 秒：2 个动作闭环，允许一次反制。
- 10-12 秒：3 个动作闭环，至少一次主动权转换。
- 13-15 秒：3-5 个动作闭环，必须有明确高潮和段末状态。
- Seedance 2.5 可承载更长段落，但漫剧生产仍优先按剧情节拍拆成 10-18 秒以内的可控单元；30 秒只用于一镜到底、完整追逐、群战推进或连续长段。
- MiniMax H3 默认按 4-15 秒设计；强动作建议 6-12 秒，不要把 15 秒塞满复杂招式。

### 不合格动作写法

禁止只写：

```text
两人激烈打斗。
双方快速交锋。
主角华丽反击。
剑光纵横，特效炸裂。
```

必须改成：

```text
<角色A> 从画面左侧压低肩线突进，右手刀背斜上挑向 <角色B> 手腕；<角色B> 后撤半步用剑脊格开，刀剑在画面中央短促碰撞，火星向右下飞散；<角色A> 被反震停在桌边，左脚踩碎木屑，形成下一拍被逼退的状态。
```

## 6. 镜头职责

打戏镜头按职责分配：

| 镜头职责 | 用途 | 不要做 |
|---|---|---|
| 建立空间 | 交代左右、距离、障碍物、目标 | 不塞复杂招式 |
| 起手镜 | 交代谁先动、从哪里发力 | 不让动作突然发生 |
| 接触镜 | 看清拳、脚、武器、能量与目标关系 | 不用强光遮住接触点 |
| 反应镜 | 看清受力、格挡、闪避、失衡 | 不让对手像木桩 |
| 结果镜 | 看清位移、破坏、道具变化、优势变化 | 不让状态自动复位 |
| 段末钩子 | 保留下一段可继承状态 | 不写“继续打斗” |

每个镜头写入 04 的 11 字段时：

- `焦段/光圈/景深`：服务接触可读性，不为炫技虚化关键动作。
- `机位/构图`：写清左右方位和画面层次。
- `运镜`：写摄影机位置、距离、高度、方向、速度、起止状态和禁止项。
- `主体动作/表情`：写动作链和可见反应。
- `台词与语气`：打斗高潮默认无长对白；短句必须能在动作间隙说完。
- `光影`：写清 VFX 或武器反光的来源、落点和遮挡限制。
- `限制`：写角色、武器、伤势、方向、破坏和额外人物限制。
- `下一段衔接`：写可继承状态。

## 8. 与 06 的交接

打戏交给 06 时，必须附带：

```text
【打戏 06 交接】
输出模型：

建议时长：
节奏档位：高密度动作或强钩子 / 短视频中高密度 / 电影感中速
素材预算：@图片 / @视频 / @音频 数量
必须保留：
必须避免：
段末状态：
```

模型建议：

- Seedance 2.0：4-15 秒，控制参考图数量，优先人物和场景一致性。
- Seedance 2.5：可用更长段落和更多参考，但仍按镜头职责组织，避免把多场景、多人、复杂 VFX 全塞进一段。
- MiniMax H3：优先用清晰时间块、首帧/尾帧或参考生成；素材总数、图片数、视频/音频数必须按 H3 限制筛选。

## 9. 打戏 QC 清单

输出前逐项检查：

```text
□ 战斗目的明确，不是为了炫技
□ 每名角色有不同战术和动作签名
□ 已锁定左右方位、摄影机安全侧和空间锚点
□ 每个主要动作有起手、接触/近失、反应、受力结果
□ 对手不是木桩，有防守、闪避、反制或压迫
□ 武器、道具、伤势、服装、VFX 来源连续
□ 场景破坏有账本，不自动修复
□ 贴身动作已拆镜，避免穿模
□ 群战不排队送招，有前中远景层次
□ 光效不遮挡关键接触点
□ 段末状态可被下一段继承
□ 06 输出模型、时长、素材预算和模式已明确；默认三模型并行，除非用户指定单模型
```
