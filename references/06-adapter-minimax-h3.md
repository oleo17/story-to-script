# 06 Adapter：MiniMax H3 / Hailuo H3

> 本文件用于 MiniMax H3、MiniMax H3 Max、Hailuo H3、Hailuo 3.0。它建立在 `06-core-format.md` 之上，强调多模态内容结构、首尾帧、参考生成、视频编辑、音频参考和清晰时间块。

---

## 1. 定位

MiniMax H3 适合：

1. 文生视频、图生视频、首帧/尾帧、参考生成和视频编辑。
2. 图片、视频、音频混合参考。
3. 需要较清楚时间块、镜头节拍、动作节奏和原生声音的短视频。
4. 打戏、首尾帧控制、角色动作测试和局部重生成。

MiniMax H3 默认按 4-15 秒单元设计；H3 Max 以平台实际限制为准。强动作推荐 6-12 秒，复杂文戏推荐 8-15 秒。

---

## 2. 参数建议

```text
模型：MiniMax-H3 / MiniMax-H3-Max / 按平台实际名称
模式：Text-to-Video / Image-to-Video / First-and-last-frame / Reference Generation / Video Editing
时长：MiniMax H3 为 4-15 秒；H3 Max 以平台实际限制为准
画幅：9:16 / 16:9 / 21:9 / adaptive / 按平台支持
分辨率：H3 可选 768P / 2K；H3 Max 可选 480P / 768P，按平台实际支持
音频：可写环境声、对白、同步音效、音频参考职责
```

若平台 API 要求 `ratio`、`duration`、`resolution` 等字段，代码框外给参数建议；代码框内仍只写生成画面和声音。

---

## 3. 素材限制与筛选

保守按以下限制设计：

```text
图片参考：最多 9 张
视频参考：最多 3 个片段，每段 2-15 秒，总时长不超过 15 秒
音频参考：最多 3 个片段，每段 2-15 秒，总时长不超过 15 秒
混合输入：总文件数最多 12 个
```

如果用户平台显示的限制不同，以实际平台为准。超限时优先保留：

1. 当前段主角图
2. 当前场景或首帧图
3. 关键道具图
4. 动作/运镜参考视频
5. 声音参考
6. 风格参考转成文字

---

## 4. H3 内容结构

MiniMax H3 更适合把素材职责写清楚：

```text
素材职责：
@图片1：定义 <角色A> 的外貌、服装和体态。
@图片2：定义当前场景的空间结构和光线。
@图片3：作为首帧，只锁定第 0 秒构图和站位。
@视频1：只参考动作速度和摄影机跟拍，不参考人物身份。
@音频1：只参考环境声或语气质感。
```

后续提示词只用 `<角色名>` 指代人物，不反复堆 `@图片N`。

---

## 5. H3 时间块版

MiniMax H3 的多镜头提示词建议使用时间块或镜头块。默认结构：

```text
素材职责：
场景与角色：
时间线：
0-3秒：
3-6秒：
6-10秒：
10-15秒：
声音：
保持项：
避免项：
结尾状态：
```

时间码是节奏指导，不承诺逐帧精确。不要每一秒都塞动作；每个时间块只完成一个主要镜头职责。

---

## 6. 图生视频 / 首尾帧

### 首帧

```text
使用 @图片N 作为第一帧，只锁定开始构图、人物初始姿势、道具位置、空间侧别和光影方向。后续动作按时间线自然发展，不复制图片中的静止姿势到全片。
```

### 首尾帧

```text
使用 @图片N 作为第一帧，使用 @图片M 作为最后一帧。视频需要从第一帧的站位和姿势自然过渡到最后一帧的段末状态；中间动作必须解释位移、道具变化和情绪变化。
```

首尾帧之间若动作过多，拆成多个 H3 单元，不要硬塞。

---

## 7. 打戏适配

从 04F 接收打戏 Clip 合同后，H3 提示词必须写：

```text
战斗目标：
空间轴线：
动作时间线：
接触点：
受力与反应：
武器/道具连续性：
声音：
避免项：
结尾状态：
```

打戏时间块示例结构：

```text
0-3秒：建立左右方位和距离，<角色A> 在画面左侧，<角色B> 在画面右侧，摄影机保持在两人正前方这一侧。
3-6秒：<角色A> 起手攻击，写清路径和接触点；<角色B> 格挡或闪避，写清受力方向。
6-10秒：主动权变化，写清位移、武器状态和环境反馈。
10-12秒：段末结果，写清谁占上风、双方距离和下一段可继承状态。
```

禁止用“快速激战”替代动作因果。

---

## 8. 视频编辑 / 参考生成

编辑视频时，直接写：

```text
严格编辑 @视频1：保留原视频的主体身份、场景空间、动作节奏和镜头方向；只修改____。不要改变____。
```

参考生成时，写清：

```text
@视频1 只参考动作节奏和运镜，不参考人物外貌、服装和场景。
@图片1 只参考角色身份。
@图片2 只参考场景。
```

不要把 `@视频1` 同时当动作、风格、身份、构图和场景。

---

## 9. H3 自检

```text
□ 时长是否在平台限制内
□ 图片/视频/音频数量是否超限
□ 每个素材职责是否单一
□ 首帧/尾帧是否只控制起点/终点
□ 时间块是否覆盖完整且不重叠
□ 每个时间块是否只有一个主要职责
□ 打戏是否写清接触点、受力方向和段末状态
□ 声音是否与画面来源同步
□ 代码框内没有平台参数、内部编号和管理话术
```

收束文案按 SKILL.md「收束文案触发条件」判断：仅在用户提供第三方受版权素材并据此拆解或仿写时追加；原创内容不追加。
