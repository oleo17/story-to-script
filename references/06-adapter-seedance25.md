# 06 Adapter：Seedance 2.5

> 本文件用于 Seedance 2.5 / Dreamina Seedance 2.5 / Doubao Pro Seedance 2.5 / BytePlus ModelArk Seedance 2.5。它建立在 `06-core-format.md` 之上，强调长段叙事、多模态参考、多轮延长、复杂转场和更强连续性。

---

## 1. 定位

Seedance 2.5 适合：

1. 15-30 秒完整段落。
2. 多镜头连续叙事、场景转换、角色穿场、追逐和打戏。
3. 多主体、多参考素材、多轮延长。
4. 需要音画同步、动作连续、镜头转场更稳定的成片段落。
5. 已有角色图、场景图、首帧图、动作参考、运镜参考或音频参考的复杂生成。

仍然不要把一整集塞进一个 prompt。漫剧生产推荐按剧情功能拆为 10-30 秒单元；高风险打戏优先拆为 8-18 秒单元。

---

## 2. 参数建议

```text
模型：Seedance 2.5 / Dreamina Seedance 2.5 / Doubao Pro Seedance 2.5 / 按平台实际名称
模式：文生视频 / 图生视频 / 参考生视频 / 视频延长 / 视频编辑 / 组合任务
建议时长：4-30 秒；打戏优先 8-18 秒；文戏完整段可 15-30 秒
画幅：9:16 / 16:9 / 21:9 / adaptive
分辨率：按平台支持；需要精细成片时优先较高分辨率
音频：按平台能力启用环境声、对白原声、同步音效；BGM 仍交给 07
```

如果用户平台仍限制 4-15 秒，按平台实际限制拆段，不强行按 30 秒写。

---

## 3. 参考素材策略

Seedance 2.5 可承载更大的多模态参考。按官方发布说明的上限设计时，可暂按单次最多 `30` 张图片、`10` 个视频片段、`10` 个音频片段做预算；如果用户使用的平台入口限制更低，以实际平台为准。每个素材必须职责单一：

| 素材类型 | 用途 |
|---|---|
| 角色图 | 只锁人物外貌、服装、发型、体态、身份 |
| 场景图 | 只锁空间结构、固定物、透视、光源 |
| 首帧图 | 只锁第 0 秒构图、站位、道具、光影方向 |
| 视频参考 | 只锁动作、运镜、节奏或上一段成片延长，不同时承担身份和场景 |
| 音频参考 | 只锁环境声、语气、音效质感或节奏，不自动生成 BGM |
| MAP/SB | 只锁点位、路线、摄影机安全侧和空间内外关系 |

素材多不等于全部引用。每段先保留当前段必需素材，低风险资产转成文字约束。

### 素材筛选优先级

1. 当前段核心角色图。
2. 当前段场景母版或首帧图。
3. 关键道具图。
4. MAP/SB/SCV 等空间参考。
5. 动作或运镜参考视频。
6. 音频参考。
7. 风格参考。风格参考优先转文字，除非它对本段成片非常关键。

## 4. 输出模式

| 情况 | 推荐模式 |
|---|---|
| 普通 10-20 秒剧情段 | C 导演轨纯净版 |
| 15-30 秒多镜头连续段 | C 加“软节奏分段” |
| 打戏、追逐、复杂运镜 | B 导演执行增强版 |
| 一镜到底或视频延长 | B 或 C，必须写清第一帧状态和段末状态 |
| 用户要审查 | A 标准字段化详细版 |

Seedance 2.5 可以写更长软时间结构，但仍避免硬性逐秒堆满。推荐写：

```text
前段：建立空间和目标。
中段：完成动作推进和反制。
后段：交代结果、反应和段末状态。
```

只有用户明确要求或平台支持时间级编辑时，才写精确时间段。

## 5. Seedance 2.5 纯净结构

```text
特别注意：
素材锚定：
参考/连续性声明：
场景锚定：
镜头轨：
1｜建立空间/目标｜镜头/焦点｜动作/台词｜光影/转接
2｜推进/交锋/信息增量｜镜头/焦点｜动作/台词｜光影/转接
3｜反转/结果/段末钩子｜镜头/焦点｜动作/台词｜光影/转接
软节奏分配：
声音轨：
硬锁：
段末状态：
```

打戏或强动作段必须加入：

```text
动作因果：每次主要攻击都写起手、接触或近失、对手回应、受力方向、位移结果。
空间连续：明确角色左右方位、摄影机安全侧、武器位置和场景破坏延续。
```

## 6. 视频延长写法

真正执行延长时，纯净提示词开头写：

```text
使用 @视频1 作为上一段成片视频，只从上一段末尾继续自然延长，接入本段动作。不重置角色身份、服装、发型、场景空间、光线方向、镜头方向、声音环境和道具状态。
```

随后继续写镜头轨。不要只写“参考上一段”，必须明确“从上一段末尾继续”。

---

## 7. 打戏适配

从 `04f-fight-scene-director.md` 接收打戏 Clip 合同后：

1. 优先 B 导演执行增强版。
2. 镜头轨每镜保留一个主要打斗职责。
3. 光效和 VFX 不能遮挡接触点。
4. 30 秒打戏必须拆成阶段：建立空间、第一次交锋、主动权变化、高潮接触、段末状态。
5. 如果一段含超过 5 个动作闭环、超过 2 次场景转换或超过 2 个 VFX 状态变化，优先拆成连续单元。

---

## 8. Seedance 2.5 自检

```text
□ 目标平台是否真的支持 2.5 和当前时长
□ 素材职责是否清楚，没有一图多用到冲突
□ 长段是否有前中后结构，而不是一串动作堆叠
□ 多镜头转场是否写成可见动作或镜头运动
□ 视频延长是否明确从 @视频 末尾继续
□ 打戏是否保留接触点、受力结果、对手反应和段末状态
□ 声音轨是否只写环境声、对白、同步音效，BGM 留给 07
□ 内部编号是否已翻译成自然语言
```

收束文案按 SKILL.md「收束文案触发条件」判断：仅在用户提供第三方受版权素材并据此拆解或仿写时追加；原创内容不追加。
