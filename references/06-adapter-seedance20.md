# 06 Adapter：Seedance 2.0

> 本文件保留原 `story-to-script` 的 Seedance 2.0 工作方式，并把它纳入多模型 06 总控。具体格式、素材映射、A/B/C 模式、字数和纯净度规则仍以 `06-core-format.md` 为底座。

---

## 1. 定位

Seedance 2.0 适合：

1. 4-15 秒短剧段落。
2. 竖屏漫剧、真人短剧、普通剧情分镜。
3. 角色图、场景图、首帧图、调度图数量可控的多模态参考。
4. 同场景视频延长、图生视频、参考生视频和文生视频。

默认使用中文字段化导演提示词，官方素材引用优先写 `@图片N / @视频N / @音频N`；第三方接入端可兼容 `@ImageN / @VideoN / @AudioN`。

---

## 2. 参数建议

```text
模型：Seedance 2.0 / Seedance 2.0 Fast / 按平台实际名称
模式：文生视频 / 图生视频 / 参考生视频 / 首尾帧 / 视频延展
时长：4-15 秒
画幅：9:16 / 16:9 / 1:1 / 4:3 / 3:4 / 21:9 / adaptive
分辨率：720p，平台支持时可选 480p 或 1080p
是否生成音频：按平台能力和需求
seed：留空或固定整数
```

短剧和漫剧默认 `9:16`；电影感横屏默认 `16:9` 或 `21:9`。

---

## 3. 输出模式

默认：

- 普通剧情：C 导演轨纯净版。
- 打戏、追逐、复杂运镜、多人调度：B 导演执行增强版，或先用 B 思路生成再压缩为 C。
- 1-3 镜高精度检查：A 标准字段化详细版。

Seedance 2.0 单段不要超过 15 秒；超过时按剧情、镜头边界、台词节拍或段末状态拆成连续单元。

---

## 4. 素材预算

沿用 `06-core-format.md` 的保守规则：

1. 每个 Seedance 2.0 单元实际图片参考最多 9 张。
2. 角色、当前场景、关键道具、首帧或调度图优先。
3. 低风险风格参考转写成文字，不占图片预算。
4. 场景母版只参考固定环境、透视、光源和固定物；不继承空无一人的状态。
5. FF 首帧只锁第 0 秒，不替代整段动作和段末状态。

---

## 5. 常用纯净结构

```text
特别注意：
素材锚定：
参考/连续性声明：
场景锚定：
镜头轨：
1｜镜头功能标签｜镜头/焦点｜动作/台词｜光影/转接
2｜镜头功能标签｜镜头/焦点｜动作/台词｜光影/转接
声音轨：
硬锁：
段末状态：
```

打戏段镜头轨必须包含动作因果：

```text
起手 -> 接触点或近失 -> 对手回应 -> 受力结果 -> 段末状态
```

---

## 6. Seedance 2.0 自检

```text
□ 单段 4-15 秒
□ 代码框外放参数，代码框内只放纯净提示词
□ 素材引用编号真实存在，且用途明确
□ 图片参考不超过 9 张
□ 内部编号已转成自然语言
□ 有对白时已检查自然语速
□ 打戏段未丢接触点、受力结果和左右方位
□ 段末状态可继承
```

收束文案按 SKILL.md「收束文案触发条件」判断：仅在用户提供第三方受版权素材并据此拆解或仿写时追加；原创内容不追加。
